# App Icons

Place your app icons in this directory:

- **icon.png** - For Linux (512x512 px recommended)
- **icon.ico** - For Windows (256x256 px recommended)
- **icon.icns** - For macOS (512x512 px recommended)

You can create icons from a PNG file using online converters or tools like:
- https://www.icoconverter.com/ (PNG to ICO)
- https://cloudconvert.com/png-to-icns (PNG to ICNS)

For now, the app will use Electron's default icon. To add custom icons:

1. Create a 512x512 PNG image with your desired icon
2. Convert it to .ico and .icns formats
3. Place all three files in this directory
4. Rebuild the app

Recommended design: A credit card or percentage symbol with a modern, clean look.
